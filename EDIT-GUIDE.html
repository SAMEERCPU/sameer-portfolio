1. Before you start

What you need

A free program called Visual Studio Code (search "VS Code download"). It shows your files in colour and makes finding text easy. Windows Notepad also works, but VS Code is much easier.

To open your site: install VS Code, then File → Open Folder and choose the vanilla-portfolio folder. Your files appear on the left.

Rule 1: Make a backup. Copy the whole vanilla-portfolio folder and paste it somewhere else (name it backup). If you break something, copy the files back.
Rule 2: Extract the zip first. Never open the website from inside the zip file. Right-click the zip → Extract All.
Rule 3: See your change. After editing, press Ctrl + S to save. Then go to your browser (open index.html) and press Ctrl + F5 to refresh. If the change is not there, you probably edited a different file than you thought.

Tricks you will use all the time

3. Change words that already exist

Website files are mostly your normal text with little codes in < > brackets around it. The golden rule:

Only change the words that are between > and <. Never delete or change the < > symbols or the words inside them.
  1. Open the page file (for example experience.html).
  2. Press Ctrl + F and type a few words from the text you want to change.
  3. Click into the text, change the words, keep everything in < > as it is.
  4. Ctrl + S, then refresh the browser.

Example. Before:

<h3>Internship &mdash; AMO (Approved Maintenance Organization)</h3>

After (only the words changed, the <h3> and </h3> stay):

<h3>Internship &mdash; Approved Maintenance Organization</h3>

Special letters

If you type these directly the site may show them wrongly, so write them like this:

You wantType this
& (and sign)&amp;
— (long dash)&mdash;
– (short dash, for date ranges)&ndash;
· (middle dot)&middot;
< or > in your text&lt; or &gt;

A normal apostrophe like don't is fine.

4. Add a new experience

An experience is one box on the Experience page. You add a new one by copying a ready-made block and pasting it in the right place.

  1. Open experience.html in VS Code.
  2. Press Ctrl + F and search for NEW EXPERIENCE GOES HERE. You will find a note (a comment) I left for you.
  3. Click on the empty line just under that note.
  4. Click Copy on the block below, then press Ctrl + V to paste.
  5. Change the words that say YOUR JOB TITLE HERE, the dates, the company, headings and bullet points.
  6. Ctrl + S, refresh the browser. Your new job appears at the top (newest first).

Small things you may want

  • More bullet points: copy one whole line <li>...</li> and paste it below itself, then change the words.
  • More headings: copy a heading line plus its list (the <div class="project-subhead"> line and the <ul>...</ul> under it) and paste it below.
  • No headings needed? Delete the heading lines and keep one <ul> list.
Careful: paste the whole block, from the first <div to the last </div>. Pasting only half is the number one reason pages break.

6. Add your report (PDF) to a project

Each of your three big projects now has a Report box at the bottom of its full-screen view, with View report and Download buttons. Today those buttons open a small placeholder PDF so nothing is broken.

  1. Export your report as a PDF.
  2. Rename it to exactly the same name as the placeholder you are replacing: crop-health-report.pdf, research-paper-report.pdf or aerombulance-report.pdf.
  3. Put it in the folder assets/reports and choose Replace when Windows asks. That is all. No code to change.

For a new project: save the PDF in assets/reports, then in your new pop-up block change my-new-project-report.pdf to your file name (in both places). The pop-up block in section 5 already includes the report box at the end.

Use simple file names: no spaces, no capital-letter surprises. my-report.pdf is good, My Report (final).pdf will cause trouble.

7. Hide or delete something

Safest way: hide it instead of deleting. Put <!-- on a line before the block and --> on a line after the block. The block disappears from the website but stays in the file. Remove those two marks to bring it back.

VS Code shortcut: select the lines you want to hide and press Ctrl + /. Press the same keys again to bring them back.

To delete for real, select the whole block from its first <div or <article down to its matching closing tag, and press Delete. If unsure, hide it first, check the page, and delete later.

8. Change your photo, CV or contact details

Your portrait photo

Prepare your new photo, name it portrait.jpg, and put it in the images folder. Replace the old file with the same name. Nothing else to change.

Your CV

Name the new PDF Sameer_Baskota_CV.pdf and replace the file inside the assets folder.

Email, phone, LinkedIn, GitHub

These appear on several pages (the footer is on every page). Change them everywhere at once:

  1. In VS Code press Ctrl + Shift + H (this is "Replace in Files").
  2. In the first box type the old one (for example sameerbaskota821@gmail.com).
  3. In the second box type the new one.
  4. Click the "Replace All" button and save.

The same trick works for a phone number or any word you want to change on all pages.

Colours of the site

Open css/base.css. Near the top there are two groups of colour lines: the first group (under :root) is the dark theme, the second group (under [data-theme='light']) is the light theme. Change the code after the # and save. Every page updates. Search "hex color picker" on Google to get colour codes.

9. Add or change a skill

Open skills.html. Skills are small pill labels inside cards. To add a skill, find the card it belongs to (press Ctrl + F and search a skill you already have, for example Python), then copy one pill line and paste it on the line below:

<span class="tag">Your New Skill</span>

To remove a skill, delete that one line. To rename it, change the words between > and <. The small count text under a card title (like "2 languages") is typed by hand, so update it yourself.

10. Add extracurricular, training, awards

These live on the About page, in small cards near the bottom: "Training & Certifications" and "Extracurricular Activities". Open about.html in VS Code. You can add a single bullet to an existing card, or add a brand new card.

A. Add one bullet to an existing card

  1. Open about.html and press Ctrl + F.
  2. Search NEW EXTRACURRICULAR ITEM GOES HERE (or NEW TRAINING / CERTIFICATE GOES HERE for certificates and courses).
  3. Click the empty line under that note and paste this line. Change the words.
  4. Ctrl + S. The new bullet appears on the page.
<li><strong>Name of club, event or course</strong> &mdash; one sentence about what you did or learned</li>

The <strong>...</strong> part makes the name bold. You can remove those tags if you don't want bold text.

B. Add a brand new card (Awards, Volunteering, Publications, Leadership...)

  1. In about.html, search NEW CARD.
  2. Click the empty line under that note and paste the whole card below.
  3. Change the heading (Awards &amp; Achievements) and the bullet lines. Write &amp; if you need the "&" sign.
  4. Ctrl + S and refresh. The new card appears next to the others.

11. Add photos to the Gallery

  1. Make your photo smaller than 500 KB if you can, and save it as .jpg.
  2. Put it in the folder images/gallery and give it a simple name, for example research-03.jpg (no spaces).
  3. Open js/gallery.js. Ctrl + F, search NEW PHOTO GOES HERE.
  4. Click the empty line under that note and paste this line. Change the title, caption and file name.
{ category: 'research', title: 'Short title of the photo', caption: 'One sentence about the photo.', file: 'research-03.jpg' },

Only change the words inside the quote marks ' '. Keep the comma at the very end.

The category must be one of these exact words:

uav-missionscrop-healthresearch
aircraft-designinternshipevents
personal-photography

Until a photo with the matching file name is in images/gallery, the site shows a grey placeholder with the file name. Add the file and it replaces the placeholder automatically.

An apostrophe inside a caption (like Sameer's) will break the line. Write Sameer\'s with a backslash before it, or reword the sentence.

12. Put the changes on the internet

Everything above changes the files on your computer only. To update the live website, upload the files you changed to the place where your site is hosted, replacing the old ones with the same names (keep the same folders).

  • Changed text on a page: upload that one .html file.
  • Added a photo: upload the new image file to the same folder.
  • Changed colours or fonts: upload the file(s) in the css folder.
  • Edited the gallery list: upload js/gallery.js.

After uploading, open your site and press Ctrl + F5 so the browser does not show the old version. How you upload depends on your hosting company (for example a file manager in their dashboard, or GitHub). If you tell me what you use, I can write the exact steps.

Before you put it online: checklist

  • Replace the placeholder PDFs in assets/reports with your real reports.
  • Put your latest CV in assets with the name Sameer_Baskota_CV.pdf.
  • The share-preview picture images/og-image.png still has old colours. Make a new one (1200 x 630 pixels) and keep the same file name.
  • The contact form does not send messages yet (the email links work). It needs a form service. Ask me and I will connect it.
  • Test on a phone: open the site on your phone, or in Edge press F12 then Ctrl + Shift + M for the phone view.
  • Click every menu link and every "Read More" once to make sure nothing is broken.

13. If something breaks

  1. Press Ctrl + Z in VS Code several times until the page works again. Save and refresh.
  2. Still broken? Copy your backup file over the broken one.
  3. Page looks plain, white, or in the wrong style? You are probably opening a file from inside the zip. Extract all first.
  4. Part of the page is missing or looks jumbled? Usually a < or > was deleted, or a block was pasted only halfway. Re-copy the block and paste it fresh.
  5. Cannot fix it? Send me the file and say what you changed. I will find the problem.
